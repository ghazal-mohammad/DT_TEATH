# 📋 قائمة الـ APIs — قسم المخبر + قسم المستودع (API's List)

> مبنية على **واجهاتي الفعلية** + **ملف التقرير (SRS)** — أدوار: رئيس المخبر (Ac4) ورئيس المستودع (Ac5).
> الأسلوب: قائمة أفعال مرقّمة (نفس نمط قائمة قسم المريض).
> 🟢 = جاهز ومربوط فعلاً · 🟡 = مطلوب من الباك · ⚠️ = فجوة (فيتشر بالتقرير ناقصة من الواجهة).

---

## 🔗 مشترك — لكل المستخدمين (مخبر + مستودع)

1. 🟢 تسجيل الدخول
2. 🟢 تسجيل الدخول لأول مرة (كود تحقق على الإيميل)
3. 🟢 التحقق من الكود
4. 🟢 تعيين كلمة المرور (بعد الكود)
5. 🟢 تسجيل الخروج
6. 🟢 عرض الملف الشخصي
7. 🟢 تعديل الملف الشخصي (مع رفع صورة)
8. 🟡 تغيير كلمة المرور (القديمة → الجديدة)
9. 🟡 عرض الإشعارات (مقروء / غير مقروء + عدّاد)
10. 🟡 تفاصيل إشعار / تعليم إشعار كمقروء
11. 🟡 البحث في النظام (حسب صلاحية المستخدم)

## 🧪 أولاً: قسم المخبر (رئيس المخبر — Ac4)

### أ) طلبات الأطباء (الطلبيات الواردة للمخبر)
12. 🟡 عرض الطلبيات الواردة من الأطباء (مع فلترة بالحالة)
13. 🟡 البحث عن طلبية واردة
14. 🟡 عرض تفاصيل طلبية واردة
15. 🟡 قبول / رفض طلبية
16. 🟡 تغيير حالة الطلبية (جديدة → قيد التصنيع → جاهز للاستلام)
17. ⚠️🟡 تسجيل تكلفة الطلبية (مطلوب بالتقرير — تأكّد من وجود حقل التكلفة بالواجهة)
18. ⚠️🟡 توكيل/إسناد الطلبية لمخبري معيّن (ربط الطلب بفني منفّذ)

### ب) إدارة المخبريين (الفنيين)
19. 🟡 عرض قائمة المخبريين (الاسم + الوردية + المهمة الحالية + مشغول/متاح)
20. 🟡 عرض تفاصيل مخبري
21. 🟡 إضافة مخبري
22. 🟡 تعديل مخبري
23. 🟡 حذف / تعطيل مخبري

### ج) مواد المخبر + الطلب من المستودع
24. ⚠️🟡 عرض المواد المتبقية داخل المخبر (مخزون داخلي للمخبر)
25. ⚠️🟡 البحث عن مادة داخل المخبر
26. ⚠️🟡 تعديل كمية مادة داخل المخبر (إنقاص/استهلاك)
27. 🟡 عرض مواد المستودع المتوفرة (لأجل الطلب)
28. 🟡 البحث عن مادة في المستودع
29. 🟡 عرض تفاصيل مادة
30. 🟡 طلب مواد من المستودع (اختيار المواد + الكميات)
31. 🟡 عرض الطلبات الصادرة إلى المستودع (+ حالة كل طلب)

### د) التقارير والتنبيهات
32. 🟡 عرض تقارير المخبر (صادر / وارد / نسب الاستهلاك)
33. 🟡 تقارير أداء المخبريين (عدد الطلبات المنفّذة + متوسط وقت التنفيذ)
34. 🟡 تنبيه الطلبات اليومية (طلبات يجب تسليمها/إنهاؤها اليوم)
35. 🟡 تنبيه نقص المواد (وصول مادة للحد الأدنى)

### هـ) إدارة منتجات المخبر  ⚠️ (ميزة بالتقرير — ناقصة من الواجهات)
36. ⚠️🟡 عرض منتجات المخبر (الكتالوج)
37. ⚠️🟡 إضافة / تعديل منتج

## ⚠️ ملخّص الفجوات — فيتشرات بالتقرير ناقصة من واجهاتي (لازم نزبّطها)

> مُحدّث بعد فحص الكود الفعلي (مو الموك).

### فجوات حقيقية — ✅ كلها انبنت وتأكّدت بصرياً:
| # | الفجوة | مرجع التقرير | الحالة |
|---|--------|--------------|--------|
| 1 | مخزون داخلي للمخبر (عرض/بحث/إنقاص كمية) | UC72 / UC73 / UC75 | ✅ صفحة `/lab/inventory` — جدول + فلاتر فئات + بحث + تسجيل استهلاك |
| 2 | إدارة منتجات المخبر (كتالوج المنتجات) | متطلب رئيس المخبر | ✅ صفحة `/lab/products` — جدول + إضافة/تعديل + تفعيل/إيقاف |
| 3 | تسجيل تكلفة الطلبية + حالة "قيد التصنيع" | UC69 + متطلب رئيس المخبر | ✅ مودال المعالجة صار 3 حالات (قيد التصنيع/جاهز/غير متوفر) + حقل تكلفة |
| 4 | تسجيل منفّذ الطلب (الفني على الطلب) | UC70 / UC71 | ✅ التوكيل بيخزّن الفني وينقل الحالة لقيد التصنيع + يظهر بتفاصيل الطلب |
| 5 | سجل حركات إدخال/إخراج للمادة | UC81 | ✅ عمود "حركة" بصفحة المواد + مودال إدخال/إخراج يحدّث الكمية |

> **ملاحظة الربط:** كل الفجوات منفّذة UI + mock. عند جاهزية الباك، تُربط بالـ APIs:
> `GET/POST /api/lab/inventory(+/{id}/consume)` · `GET/POST/PUT /api/lab/products` ·
> `PUT /api/lab/orders/{id}` (status+cost+technician) · `POST /api/warehouse/materials/{id}/movement`.

### 🔧 تدفّق إنجاز طلبية المخبر (متّفق عليه مع الباك):
1. **القبول/تغيير الحالة:** `PUT /api/lab/orders/{id}` — يرسل `status` (جديد/قيد التصنيع/جاهز) + `technician_id` (المنفّذ) + **`cost`**.
2. **التكلفة `cost`:** **يدخّلها المخبري يدوياً** (الباك يخزّنها كرقم). الفرونت **يقترحها تلقائياً** من تكلفة المواد المستهلكة لكن المخبري حر يعدّلها.
3. **استهلاك المواد عند الإنجاز:** `POST /api/lab/orders/{id}/consume` مع `[{material_id, quantity}]` → ينقص **مخزون المخبر** ويسجّل الحركة. (منفصل عن `cost`.)

### ✅ تبيّن إنها موجودة فعلاً (مو فجوات):
- **إضافة فاتورة** بالمستودع — موجودة (`warehouse_invoice_form_dialog`).
- **توكيل طلبية لمخبري** — مودال موجود (بس ناقصو يخزّن الفني — انظر فجوة 4).
- **CRUD المواد بالمستودع** — كامل عبر cubit + form dialog.

## 📝 ملاحظات للباك
- كل endpoint محمي بـ `Authorization: Bearer <token>`.
- منرسل `Accept-Language: ar | en`.
- القوائم الطويلة (مواد/طلبيات/فواتير/إشعارات) يا ريت pagination (`page`, `per_page`).
- التواريخ بصيغة ISO 8601.
- الأسماء الفعلية لـ endpoints بتحددها أنتي من Laravel — هاي القائمة بالوظائف بس.
